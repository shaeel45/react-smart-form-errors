# Changelog

All notable changes to this project will be documented in this file.

## [2.0.2] - 2026-06-02

### Added

- Added `useSmartForm` hook.
- Added built-in validators.
- Added support for email, phone, password, DOB, full name, username, URL, number, length, pattern, and custom validation rules.
- Added smart error messages.
- Added TypeScript declarations.
- Added Microbundle build support.
- Added Vitest testing setup.

### Fixed

- Fixed npm package entry points.
- Fixed Vite import resolution issue.
- Fixed form values initialization issue.
- Fixed errors and touched state handling.

## [1.0.2] - 2026-06-02

### Added

- Initial npm package release.
- Added `useFormErrorTranslator`.
